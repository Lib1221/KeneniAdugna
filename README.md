
# Keneni Adugna Memorial App

A heartfelt tribute to **Keneni Adugna**, a talented Ethiopian model, engineer, and inspiration. This application is designed to honor her memory, showcasing her life and achievements through a beautifully crafted multimedia platform. It features an **image gallery**, **grid system**, and **video playback** functionality, similar to TikTok, while also sharing her inspiring story. The app leverages **Cloudinary** for media storage and **Firebase** for backend support.

---

## 🌟 About Keneni Adugna

Keneni Adugna was a brilliant 25-year-old Ethiopian model and engineer whose life was tragically cut short. She was a trailblazer, breaking barriers in both modeling and engineering, and inspiring countless individuals with her resilience, talent, and ambition. Keneni's story is one of hope and empowerment, and this app serves as a digital memorial to preserve her legacy for future generations.

---

## 📱 Features

### 1. **Image Gallery**
   - A visually stunning gallery showcasing images related to Keneni's life, achievements, and legacy.
   - Dynamic grid system provides an organized and aesthetic display.

### 2. **Video Features**
   - Video playback functionality inspired by TikTok's immersive scrolling experience.
   - Short clips highlighting Keneni's story and contributions.

### 3. **About Section**
   - A dedicated section narrating Keneni's remarkable story.
   - Includes text, images, and videos to take users through her journey.

### 4. **Cloudinary Integration**
   - Handles optimized storage and delivery of high-quality images and videos.
   - Ensures seamless performance across devices.

### 5. **Firebase Integration**
   - Powers secure media storage, real-time database, and user authentication.
   - Ensures reliable backend infrastructure.

## 🚀 Getting Started

Follow these steps to set up and run the app locally:

### Prerequisites
- Install **Flutter SDK**: [Flutter Installation Guide](https://flutter.dev/docs/get-started/install)
- Set up **Firebase** and configure your project.
- Create a **Cloudinary** account and obtain your API keys.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Lib1221/KeneniAdugna.git
   cd KeneniAdugna
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Configure Firebase:
   - Add your `google-services.json` (for Android) and `GoogleService-Info.plist` (for iOS) files to the project.

4. Configure Cloudinary:
   - Add your Cloudinary API keys in the app's configuration file.

5. Run the app:
   ```bash
   flutter run
   ```
